# 🌱 SmartCrop AI  
## AI-Powered Plant Disease Detection & Farming Assistant

SmartCrop AI is a deep learning-based application that helps farmers identify plant diseases using leaf images and provides smart farming assistance.

The application uses Artificial Intelligence to detect diseases, suggest treatments, recommend fertilizers, provide watering guidance, and give seasonal crop recommendations.

---
## 🚀 Features

### 🌿 Plant Disease Detection
- Upload a plant leaf image
- AI model predicts the disease
- Displays confidence percentage

### 🌐 Multilingual Support
- English language support
- Tamil (தமிழ்) language support for farmer-friendly usage

### 💊 Disease Management
- Disease information
- Symptoms
- Prevention methods
- Treatment suggestions

### 🌾 Smart Farming Assistance
- Fertilizer recommendation
- Watering advice
- Seasonal crop recommendations
- Farming tips based on season

 ## 🧠 Model Information
-Model: Convolutional Neural Network (CNN)
-Dataset: PlantVillage Dataset
-Number of Classes: 38
-Input Image Size: 224 × 224

 ## 🌱 How It Works
1.Upload a plant leaf image
2.AI model analyzes the image
3.Disease is predicted
4.User receives:
   -Disease name
   -Confidence score
   -Treatment
   -Fertilizer suggestion
   -Watering advice
   -Seasonal farming guidance
